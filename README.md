# Discord-Privacy-Policy-analysis
Discord Privacy & Security Governance Review

## Overview
This project aims to evaluate publicly observable privacy and security practices of Discord from a user-centric GDPR and cybersecurity governance perspective.

## Objectives
- Evaluate Discord’s data collection and processing practices using publicly available documentation.
- Identify privacy and security risks associated with user data handling and platform architecture.
- Assess the clarity, structure, and accessibility of publicly provided privacy and security documentation.
- Identify ambiguous, broad, or non-specific language in privacy and data processing policies.
- Review publicly disclosed security incidents and official responses to understand incident handling and governance maturity.
- To structure recorded findings into a clear overview

## Scope
The analysis is limited to publicly available documentation provided by Discord, including:
- Privacy Policy
- Terms of Service
- User-facing settings and documentation
- Publicly disclosed incidents and reports  

Out of scope:
- Internal systems
- Non-public APIs
- Active exploitation or penetration testing
